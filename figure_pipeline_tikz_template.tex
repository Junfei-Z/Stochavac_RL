\caption{Three-stage framework for prior-guided reinforcement learning.
\textbf{(M1)} Population-level ODE simulations generate expert trajectories using
tractable optimal control methods.
\textbf{(M2)} A macro-to-micro lifting algorithm maps group-level actions to
individual allocations, which are used to train a conditional diffusion model
$p_\theta(a \mid s)$ capturing expert strategy distributions.
\textbf{(M3)} A PPO agent optimizes individual-level vaccination policies on the
CTMP environment, regularized by KL divergence to the diffusion prior (blue dashed arrow).
This hybrid approach combines the theoretical insights of optimal control with the
scalability of RL, achieving 2× faster convergence than baseline methods.}
